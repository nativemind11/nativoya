# فيدباك الشركة — دليل سريع

**الصفحة:** `studio/feedback.html` (من لوحة الهيد ليدر ← 📝 فيدباك الشركة)

## شكل الملف اللي بيتقبّل
أي ملف Excel (`.xlsx`) أو CSV. المهم 3 أعمدة، أسماؤها وترتيبها حر (بتختارهم بنفسك):

| عمود | مثال | ملحوظات |
|---|---|---|
| الاسم | `Eagle` أو `Eagle-male-adult-30.zip` | اسم مستعار، أو اسم ملف الـ ZIP كامل |
| أرقام التسجيلات | `3` أو `3, 5, 7` أو `2-4` أو `٣ و ٥` أو `all` | الرقم 1 = أول جملة (زي ما المتسجّل بيشوفها) |
| وصف المشكلة (اختياري) | `فيه صدى` | بيظهر للمتسجّل والليدر |

## اللي بيحصل
1. ترفع الملف وتختار المهمة → النظام بيقترح الأعمدة.
2. **معاينة:** كل صف بيتربط بمتسجّل (اسمه + إيميله + ليدره)، والصفوف الغلط بتظهر بسبب الخطأ ومش هتتطبق.
3. **تطبيق:** التسجيلات المذكورة بس بترجع للمتسجّل، ويبدأ عداد 12 ساعة. الفيدباك بيظهر في حساب المتسجّل وحساب الليدر.
4. المتسجّل يعيد التسجيلات ويبعت ← بيرجع لـ QA ← بعد الموافقة بيظهر تاني في "في انتظار التسليم" بعلامة 🔁.

## ملاحظات
- التاسك اللي اتسلّم قبل كده لشركة: أرشيف "تم التسليم" بيفضل زي ما هو، والنسخة المعادة بتتسلّم كتسليم جديد.
- مهلة الـ 12 ساعة بتظهر وبتتحسب "متأخر"، لكن مفيش حاجة بتمنع المتسجّل يخلّص بعدها (قرار لسه مستني تأكيدك).
